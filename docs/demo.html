Building Lighting Demo

Explore Building Control with a simulated connection and the dashboard, then see a three-floor building created from a blank design. The address strip is included for the recordings. Both videos use VP8 WebM for preview compatibility.

Building lighting and instrumentation

Orbit, pan and zoom through the default building, then follow presence, a sensor fault and the occupancy demo in the instrumentation dashboard. Each control is shown for 1.5 seconds before selection, with three-second holds on presence and fault results and a six-second occupancy hold before leaving the building view. The final dashboard view was recorded separately with matching room occupancy and lighting counts.

If the video doesn't play, download the lighting walkthrough.

Text summary of the walkthrough
  1. Orbit, pan and zoom the building, explore all four floor views, and orbit Floor 3.
  2. Turn on presence in Floor 3's Collaboration Space; six lights turn on and the dashboard reports one occupied room.
  3. Enable its sensor fault and see the dashboard report one active fault. The faulted sensor no longer reports occupancy; the six lights remain on.
  4. Run the occupancy demo and see lights and occupancy update across the building and dashboard; faults are cleared.

Building editor

Start blank, create rooms with doors, centered sensors and evenly spaced lights, add interior walkways and stairs, then save and activate the design. Short recording chapters are joined without speeding up the actions: tool selections pause before and after clicking, and each plan placement has a one-second result hold. Full building rotations take about four seconds in both walkthroughs.

If the video doesn't play, download the editor walkthrough.

Text summary of the editor walkthrough
  1. Start a blank building and set it to three floors.
  2. On Floor 1, create two offices with two lights each, interior walkways and a stair flight.
  3. On Floor 2, create a large office with six lights, a small office with two lights, walkways and a return stair flight.
  4. On Floor 3, create a meeting room with eight lights and walkways. Each room has a door to the corridor and a centered sensor.
  5. Save and activate the design, then orbit the three-floor building.
