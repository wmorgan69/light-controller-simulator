Building Lighting Demo

See the simulator’s building navigation and room controls, then follow sensor and fault changes in the live instrumentation dashboard.

If the video doesn't play, download the demo video.

Text summary of the walkthrough
  1. Pan and rotate the camera around the four-floor building.
  2. Select floors and rooms, then explore the room controls.
  3. Change presence and sensor-fault states in the simulator.
  4. Observe the resulting live updates in the instrumentation dashboard.
  5. Run the occupancy demo and see room occupancy updates.
