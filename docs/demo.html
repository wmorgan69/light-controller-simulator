Building Lighting Demo

See the simulator’s building navigation and room controls, then follow sensor and fault changes in the live instrumentation dashboard.

If the video doesn't play, download the demo video.

Text summary of the walkthrough
  1. Show all floors, then pan, rotate 360 degrees and zoom the building. Floor 1's Open Workspace is occupied, with six lights on.
  2. Cycle through Floors 1–4: Floors 1 and 3 have a main room and two offices, Floor 2 has a larger main room and one office, and Floor 4 has one large room. Return to Floor 3, zoom, pan and rotate it 360 degrees.
  3. Select Floor 2's Meeting Office and turn on presence. Its presence control is checked, its sensor turns green and its light comes on; the dashboard shows two occupied rooms and seven lights on.
  4. Turn on the office sensor fault. The fault control is checked and the sensor turns red; the dashboard shows one active fault and one occupied room, with seven lights still on.
  5. Select all floors and run the occupancy demo. See lights come on across the building, then see the dashboard update with several occupied rooms and no active faults. The dashboard stays visible for five seconds after each update.
