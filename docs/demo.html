Building Lighting Demo

Explore the simulator and dashboard, then see a three-floor building created from a blank design.

Building lighting and instrumentation

Orbit, pan and zoom through the default building, then follow presence, a sensor fault and the occupancy demo in the instrumentation dashboard.

If the video doesn't play, download the lighting walkthrough.

Text summary of the walkthrough
  1. Orbit, pan and zoom the building, explore all four floor views, and repeat the camera controls on Floor 3.
  2. Turn on presence in Floor 3's Collaboration Space; six lights turn on and the dashboard reports one occupied room.
  3. Enable its sensor fault and see the dashboard report one active fault. The faulted sensor no longer reports occupancy; the six lights remain on.
  4. Run the occupancy demo and see lights and occupancy update across the building and dashboard; faults are cleared.

Building editor

Start blank, create rooms and place lights, then save and activate the design.

If the video doesn't play, download the editor walkthrough.

Text summary of the editor walkthrough
  1. Start a blank building and set it to three floors.
  2. On Floor 1, create two offices with two lights each.
  3. On Floor 2, create a large office with six lights and a small office with two lights.
  4. On Floor 3, create a meeting room with eight lights.
  5. Save and activate the design, then view the three-floor building.
